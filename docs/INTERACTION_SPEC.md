# 夜栖交互规范

## 音频专项B（取代旧背景音床实现）
背景为同源打包的许可钢琴录音，首次明确开启后才fetch/decode，按页缓存可重试；加载时可取消。取消/后台/旧请求完成不会意外开声。解码32kHz、调整整体增益、裁去外侧过静尾段，并在PCM中做8秒等功率尾首重叠，由一个AudioBufferSource循环，不按页面重建或同时启动多份。暂停保留循环位置，恢复3秒柔起，保留旧音量/偏好/静音与自动播放限制；加载失败明示，不能回退到已被否定的嗡鸣。
音乐来源/许可/处理说明在音景设置可见；链接仅用户点击时打开，noreferrer；运行播放不请求外部音频服务。背景不叠额外合成铺底，其他数据与页面行为不变。

## 音频专项C：星铃触碰
- pointerenter（非触屏）、focus、click均进入同一扰动函数，同一挂件1.8秒内去重，不因焦点/点击或鼠标像素移动重复打击，不延长当前视觉计时。触屏由焦点/点击去重响应，键盘Tab/Enter可操作。
- 接受扰动时同步安排约15ms后的接触声；默认一击，约22%弱二击，第二击延迟0.25—0.36秒，均在早期摆动内；不在停止后再演奏新音。模态接触的自然衰减可继续消散。
- 全局星铃冷却1400ms，单次声源2.6秒，并以独立集合硬限制最多两份本体声源；声音结束/暂停清理集合。上下文不在running时不排队发声。左右声像轻分，星铃独立轻混响。音乐短暂退到85%再恢复，单独duck增益不绕过静音或音量设置。
- 音效关闭、音效音量零、未主动激活或后台时均不生成声音；视觉可保持。减少动态效果取消摇摆，仍允许有授权的轻触声音。月亮仍可摇摆/切换月相，用普通轻提示，不播放玻璃星铃乐句。

## 纸艺小剧场（统一任务阶段5）
/theatre可独立停留：星铃触碰按上方专项C规则，月亮切换月相与纸窗。点击守灯人切换短句/灯光，书本显示真实计数，抽屉展示最新草稿并进入续写，纸门回顾真实记录（空时说明并去档案馆），复位恢复场景。机关是有名称的原生按钮，支持键盘与触摸；无自动开启声音。倾斜仅鼠标移动时requestAnimationFrame，卸载清理计时器；触摸与减少动态效果不倾斜。

## 独立模块（统一任务阶段4）
- /calendar按月/按日读取正式记录和心情标记，点击当天梦笺进入阅读；不代表占星预测。
- /drafts保存快速碎片，/draft/:id续写并保存草稿或转正式；删除有确认。转正式先保存日记再删除草稿，后者失败保留副本并告知。草稿仅手动保存，不自动备份尚未提交的输入。
- /wishes添加<=300字愿望、标记完成/重新进行，并筛选状态；/collection独立查看真实收藏，支持取消收藏，档案与阅读均可收藏。
- 草稿/愿望/收藏索引存于yeqi.workspace.v1，严格校验、损坏不覆盖、多页冲突阻止写入；旧日记key保持不变。常规JSON备份纳入workspace，日记损坏时同时保留单独原文导出与完整恢复包。
- 这些空间均可回到夜栖地图，不经写作中转。收藏匣没有加密或密码保护，不能用锁孔装饰暗示真正安全能力。

## 音景控制（统一任务阶段2）
顶栏音景设置控制背景音乐、音效及独立音量，默认静音。只有明确用户操作才创建或恢复AudioContext；刷新记住偏好但不自动播放。后台暂停并清理残留音符，返回后点击“恢复背景音乐”或“恢复交互音效”，两者可独立恢复。音乐单实例原生循环，关闭淡出；短音效有节流，不因快速悬停叠加风铃。无音频支持时提示并保留静音使用。音景参数仅存yeqi.audio.v1，不含私人正文，不调用网络服务。

历史背景方案（已被本轮专项B替代）：去掉分步音符调度与和声更替，单个原生AudioBufferSource循环32秒周期音床；整周期波形与音色曲线连续，播放不依赖主线程定时补音。6秒柔起，暂停保存循环位置，恢复从原位置重新淡入。音乐与音效独立滤波/混响，总音量位于干声与混响之后，零音量同时静音余韵；关闭淡出，后台清理声音与混响。开发热更新时注册旧音景暂停，避免模块替换留下旧声音。偏好与音量不重置。通用轻提示chime与剧场windchime独立，普通页面切换不播放整段星铃。

## 页面导航与仪式过渡

- 统一任务阶段3新增/rooms夜栖地图：首页和常驻导航均可进入；八个空间独立标明价值。未实现项必须标“筹备中”并禁用，完成后才开放。各模块有返回地图入口，档案与回响不经写作中转。

- 进入书写/编辑/草稿续写/剧场：拉开帷幕；进入档案/草稿匣/收藏：打开柜门；档案条目/保存→阅读：解封信纸；回响/月历：拨动星盘；返回首页及其他空间：经过月影门。
- 正常模式：640ms合拢、160ms闭幕停顿后切页，1000ms展开，总计1800ms。参数由lib/ritual.ts统一管理；闭幕时衬层完全遮挡页面。过渡期间应用inert，结束后解除锁定、聚焦主标题并回到页顶。减少动态效果仍立即切换。
- 单次过渡中重复内部导航不再发起第二次；浏览器历史导航能中断前一过渡，清除旧定时器，恢复正确目标。
- prefers-reduced-motion：不显示过渡，立即切页；途中启用则立即收尾，保留已提交的历史位置，不新增重复历史条目。
- 使用 hash 地址与 History API 管理同一应用内的前进/后退；历史位置标记仅在 history.state，不写入私人记录。
- 首页钥匙和明确的书写按钮均实际进入书写；档案抽屉条目实际打开记录；回响按钮随机读取真实记录。首页星盘线条、档案柜体拉手和烛台为装饰；剧场纸门/人物/星月/书/抽屉是原生按钮，有明确名称与反馈。
- 常驻章节索引可访问首页、书写、档案、回响与地图；地图八个模块均可用。桌面侧栏/移动页底有备份和隐私入口。无效记录有返回档案的下一步。

## 创建、编辑与草稿保护

Entry 保存 id、可选 title、必填 body、mood、tags、occurredAt、createdAt、updatedAt。

- 标题<=80字，正文非空且<=20000字，标签<=8个、每个<=20字；中英文逗号/顿号/换行分隔并去重；编辑界面时间为1900—2100年的有效日期。
- 五种心情：晴光（开心/轻松）、月雾（平静/疲惫）、暗潮（难过/烦躁）、星火（期待/兴奋）、夜雨（迷茫/低落）。颜色之外保留名称、含义和符号；自定义感受用标签补充。
- 心情仍用原生 radio，切换仅带动装饰月相，不重建输入框，不打断写作。
- 保存先校验、成功持久化后才更新页面和显示成功反馈；失败保留输入并提示，正文始终以纯文本显示。
- 内容改变后离开时显示“未封好的信”主题 dialog；“继续写信”/Escape 保留输入，“放弃修改并离开”明确丢弃未保存修改。
- 浏览器后退触发确认时先回到原历史条目，确认后才前往原目标；不把前一条历史改写成书写页。取消后仍可正常再次后退和前进。
- 关闭/刷新由beforeunload提供浏览器原生提示（浏览器决定显示方式）。草稿需要手动保存；草稿匣快速输入及未提交心愿同样有离开确认，Escape/取消保留输入，不声称自动保存。

## 查看与删除

- 普通阅读与回响共用阅读组件，回响另有星盘场景。阅读操作可重新落笔、返回档案、删除。
- 删除前使用原生 dialog 的焦点约束，提供树洞图形；明确“永久删除”，不能仅用隐喻掩盖后果。
- 取消/Escape 不改数据，焦点回到打开确认框的按钮。先捕获触发焦点，再应用弹窗自动焦点。
- 删除先写入存储，成功后返回档案；失败保持记录和确认框，显示错误供用户取消或重试。

## 搜索、筛选与回响

- 搜索标题和正文，不区分大小写；心情与标签 AND 组合；按 occurredAt 升/降序；显示当前结果数和总数。
- 清除筛选恢复空关键词、全部心情/标签与时间降序。离开档案再返回会重置筛选（本版限制）。
- 回响只从真实记录随机选择，多条时避开上次；仅一条时再次点击提供提示，无记录时显示星盘空状态与书写入口。
- 直接打开/echo且已有记录时显示抽笺邀请与“抽一段今夜回响”，点击后打开真实记录；无有效记录才显示写下第一段记忆，避免将未抽取误称为无历史。
- 柜体编号只是当前显示序号，不表示创建年份或固定记录 ID。统计、摘要和列表均来自真实数据。

## 存储、备份与异常

- 原有key为yeqi.entries.v1，格式为{ schemaVersion:1, entries:[...] }，保持兼容；新增yeqi.workspace.v1为{ schemaVersion:1, data:{drafts,wishes,favoriteIds} }，与旧日记独立校验和写入。
- 读取失败/损坏时禁止覆写、显示恢复说明，允许导出原始内容；不静默清空数据。
- 容量或写权限异常必须提示“未保存”，保留输入；多标签页变化时阻止旧页覆盖，提示先复制未保存文字再刷新。
- 常规导出JSON含schemaVersion、exportedAt、entries及workspace。日记损坏时保留单独原文导出，并可导出entriesRecoveryRaw+workspace+warning的完整恢复包；附属数据损坏则保留recoveryRaw和error。没有导入/恢复界面。
- 数据只在当前浏览器/当前来源，不自动同步，清理浏览器会丢失，建议定期备份。本地存储和备份未加密，不提供设备级密码保护。
