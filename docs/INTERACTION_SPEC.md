# 交互规范

## 导航

- 首页「记忆之门」→「写下心情」→保存→独立阅读；阅读可编辑、删除或返回档案。
- 左侧/移动顶部常驻导航：记忆之门、写下心情、记忆档案、今夜回响；页底提供备份和隐私说明。
- 使用 hash 路由支持浏览器前进/后退和刷新。无效记录地址提供返回档案入口。
- 写作离开且内容改变时确认放弃（含浏览器返回）；关闭/刷新使用 beforeunload 的浏览器提示。未保存草稿仅在内存，不声称自动保存。

## 数据与流程

- Entry：id、可选 title、必填 body、mood、tags、occurredAt、createdAt、updatedAt。
- mood：晴光（开心/轻松）、月雾（平静/疲惫）、暗潮（难过/烦躁）、星火（期待/兴奋）、夜雨（迷茫/低落）；自定义感受通过标签补充。
- 正文非空，最多 20000 字；标题最多 80 字；标签最多 8 个，每个最多 20 字；时间为有效日期。正文按纯文本展示，不解析 HTML。
- 保存必须先校验并成功写入 localStorage，再更新页面；失败保留表单，显示错误。
- 删除使用可聚焦原生 dialog 二次确认，确认后先持久化，再离开；取消不更改数据。
- 存储 key `yeqi.entries.v1`，版本化 JSON；读取异常/损坏数据时禁止覆写，显示恢复说明并允许导出原始数据。不静默清空。
- 多标签页检测外部变化并阻止旧页面覆写，要求刷新；用户可复制未保存文字。
- JSON 备份包含 schemaVersion、exportedAt、entries；本版不提供导入（避免未经确认覆盖）。

## 档案与回响

- 搜索标题和正文，不区分大小写；心情和标签使用 AND 组合；时间升序/降序按 occurredAt 排列；显示结果数，清除按钮恢复默认。
- 回响只随机选择真实记录（存在多条时避开上次），无数据时引导书写。
- 所有列表、统计、最近记录均取真实数据，不注入演示内容。

## 反馈与无障碍

- 成功使用 aria-live 状态提示，错误使用 alert；删除 dialog Escape 可取消、焦点回到触发按钮。
- 页面切换将焦点移到主标题；字段有 label，心情用原生 radio；所有按钮可键盘操作，焦点明显。
- 空档案、筛选无结果、无回响、记录不存在均有明确下一步。
- 动画不阻塞操作；尊重 prefers-reduced-motion，不强制音效。
- 隐私说明：数据仅当前浏览器、当前来源；不自动跨设备同步；清理浏览器会丢失，建议定期导出；本地存储未加密，共用设备请注意。
