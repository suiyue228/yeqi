# 夜栖设计规范

## 二十二张大阿卡纳与场景通道（2026-11-05，当前规则）
用户选择完整22张大阿卡纳，并要求强化牌框、占卜流程和通道的场景融合。牌框使用独立生成的飞蛾冠饰、细金拱窗及上下题签，中间透明窗叠放原有和新增插画，编号与牌名仍是HTML。十二张原牌保留，补齐皇后、皇帝、教皇、恋人、战车、力量、倒吊人、死神、恶魔、审判十幅。正逆位旋转整张牌，牌位外标明方向，解读正文保持正常阅读。

流程采用定意、洗牌、切牌、选牌、解牌五步。三种牌阵分别是月影三问、时间之河与五张岔路星盘，布局随牌数与屏宽变化。长牌阵的桌布采用上下分段边饰，避免拉伸纹样。

裁纸间返场通道为雾青布帘门，邮局为信柜暗道，小店为星纹帘门。主房间记忆之门缩小并贴近地台，通道铭牌降低视觉权重。通道用途和去处持续用可读文字标注。

## 占星小店与十二张牌（2026-11-05初版）
用户要求第四幕占星小店、兜帽女巫店员、水晶球、精致塔罗牌和放大的占卜场景。实现采用「栖星占星小店」，店员命名为岑。深紫哥特小店背板、女巫、柜台与水晶球为独立生成素材，沿用旧金和象牙白剪纸，悬景用飞蛾，近景用烛台。

水晶球进入独立牌桌，幕布后接轻微的桌面推近。牌桌用深紫星月边饰围住安静的操作区域。原创《夜栖秘仪》本轮采用十二张大阿卡纳主题牌，图案分别为纸舟、钥匠、星帘、守灯、纺月、羽秤、潮杯、折塔、星井、双潮、晨窗、环门。三张牌阵为眼前、暗处、下一步。牌面、边框与文字分开制作，中文牌名和罗马编号采用真实网页文字。新标题所需展示字形以同源补充分片提供。

## 小剧场分层布景（2026-11-04）

## 小剧场空间修订（2026-11-03，当前空间规则）

窗框改为生成的透明镂空纸框window-cutout，保留尖拱结构并降低饰边亮度；夜空/远月在窗后独立平面。远月缩小、去彩、降低实物纸边的存在感，偏冷；前景吊月保留象牙白/金边纸艺质感。夜空仅少量静态星点，三月相均应清楚，不让窗棂把满月长期切成半月。此方案以尺度、遮挡和远近对比建立距离，不用大面积模糊或强光晕。

远景→镂空窗→树影→前置地台→门与人物→道具→前幕/吊饰分别安排深度，原背景仅复用下沿作为独立地台。阴影沿纸层边缘，明度/投影区分后墙与前幕；正常模式轻微视差，减少动态效果保留静态遮挡与切边。标题、文字、原按钮/数据/声音不变。新窗图沿用原图生成编辑，1x/2x追加约130KB；所有14项/28张共748,420字节，来源/完整prompt随manifest记录。

## 页面场景与阅读路径

- 夜栖地图采用不对称门廊刻版和纵向房间目录，作为全站探索索引；不把八个空间堆成同尺寸功能卡片。

- 首页主焦点：尖拱月影门与黑色枝影；次级组一是帷幕/蕾丝和剧场题签，次级组二是文案/明确入口与今夜索引。蛾翼、眼形吊饰、钥匙、阶梯、少量白花和蘑菇沿门框与门脚分布。
- 最近记录在舞台下方作为藏笺收藏延续，不做虚构日记。
- 书写主焦点：展开的浅色手稿；次级组为书本/羽毛笔/墨水/烛台和心情月相装置。底纸以外侧阴影表现，边饰不能侵入正文或输入焦点。
- 档案主焦点：秘密收藏柜；次级组为柜冠/藏笺铭牌和检索索引。真实记录是带编号、纸面与拉手的抽屉，标签、日期、标题与摘要须清晰。
- 阅读主焦点：展开旧信，使用折角、刺绣线框和月相分隔。回响采用同一纸面，旁置星盘抽笺台及可用的“再听一段”入口。
- 删除/放弃草稿使用树洞归还信笺图形和主题 dialog，真实删除/丢弃的含义必须明示。
- 常驻导航是章节书签；桌面侧轨、手机上方紧凑索引，操作名称保持可见。

## 符号、字体与原创性

月亮表示栖息，钥匙表示进入，封蜡表示记忆封存，抽屉表示收藏，星盘表示真实随机回顾；眼形吊饰/蛾翼为门框视觉符号，不代表监控或占卜功能。
当前字体采用顶部五角色系统；此前设备宋体是历史方案，保留作资源失败回退。网站不依赖外部字体服务。
主体插画保留原创SVG/CSS，局部道具补充同源生成插画。首页在StageArt.tsx，道具在SceneArt.tsx/DecorativeArt.tsx与public/art，剧场在PaperTheatreArt.tsx；基础变量/版式在styles.css，原有场景在scenes.css，帷幕/音景/地图/实用模块/剧场各有对应CSS。不得复制参考图中的角色、原画面、字幕或标志。

## 动态与适配

- 统一任务阶段1：过渡帷幕使用对称植物绣纹、月印、蕾丝、串珠和流苏，层叠布料保持闭幕无缺口；节奏为640ms合拢/160ms停顿/1000ms展开。

- 帷幕/柜门/信纸/星盘/月影门采用一次性过渡，主要动画用 transform/opacity，短生命周期装饰层在结束后卸载。
- 仅少量信件缓慢漂浮；星盘仅进入时旋转一次，不增加无限粒子和持续高负载效果。
- prefers-reduced-motion 下跳过过渡与漂浮；切换途中启用时立即收尾。
- 桌面保留不对称构图；761—1000px 主插画限制最大宽度，避开底部索引；<=760px 单列舞台，月影门限宽居中，幕布下方为眉题留足空间。
- 书写与筛选移动端单列/双列适配。按钮与表单可键盘操作，焦点明显，图形装饰不截获点击。
- 已检验 1440/1000/768/640/390/360 宽度。实际手机、Safari/Firefox 和屏幕阅读器尚未验证。

## 禁止方向

SaaS 仪表盘、顶部大 Hero 加三卡模板、统一圆角堆叠、厚重玻璃/霓虹/3D、廉价图片拼贴、随机铺满符号、外部图片 API。
不可用更多装饰掩盖遮挡、低对比度或布局问题。新增场景首先检查主轮廓与阅读路径，再考虑小符号。
