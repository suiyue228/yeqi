## 视觉系统

- 夜栖 · 月下树洞（Moonlit Treehole）：将情绪封存在月下记忆邮局。
- 桌面：左侧窄幅章节导航，中央粉色纸幕与原创黑色月拱门、稀疏枝影，右侧片尾式夜间索引。下方纸笺承接最近真实记录。
- 书写：大幅象牙纸、信封折线、朱红封印；档案：日期索引与错落信件；阅读：独立纸页。
- CSS 变量：墨黑 #120F18、深紫 #49306F、夜紫 #30204C、淡紫 #D8BCE8、柔粉 #F3D7DF、象牙白 #FFF5E9、旧纸棕 #92735F、星光黄 #F3D978、朱红 #B83D43。
- 主页面以墨黑框架与柔粉纸幕形成对比，黄色仅用于月亮、焦点和主入口；避免平均分配颜色。
- 中文标题使用设备宋体（SimSun / Songti SC），正文设备无衬线，英文小字用系统衬线；无网络字体依赖。
- 装饰均为原创可维护 SVG/CSS：月拱门、枝影、信件、星吊饰、点阵与线框。无参考截图、人物或第三方图片。
- 同一屏最多一个主要插画焦点，辅以留白；不靠密集装饰掩盖布局。

## 动态与适配

- 页面短暂淡入和位移；月下信件轻微漂浮，hover 反馈短促。减少动态效果时关闭动画及平滑滚动。
- <= 1000px 压缩右侧索引；<= 760px 导航转顶部，主视觉与文字顺序排列，表单单列，触摸目标至少约 44px。
- 保留可见键盘焦点、阅读对比度和文本含义；心情不能仅用颜色表示。

## 禁止

SaaS 仪表盘、标准渐变 Hero、三卡模板、厚重玻璃/霓虹、复杂 3D、外部图片 API、统一圆角堆叠、复制原作角色/字幕/标志。
