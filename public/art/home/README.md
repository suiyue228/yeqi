# 首页月影门

首页专用。使用项目现有首页构图和小剧场纸门作为风格参考，经 OpenAI 内置 image_gen 生成概念稿，再生成独立透明纸层。完整提示词、原图及输出文件的 SHA-256 见 `manifest.json`，没有使用外部角色、图库或记录内容。

| 景层 | 来源与用途 |
| --- | --- |
| `gate-night` | 淡紫背板、深紫天空与远丘。夜色越过门框内沿，移动时不会露底。 |
| 弯月 | 复用 `../theatre/moon-crescent-*.webp`，独立在夜色和门框之间。 |
| `gate-arch` | 镂空尖拱、飞蛾纹与台阶。中心保留透明，露出后方夜色。 |
| `gate-boughs` | 前景两侧的荆枝和白花，配合轻微投影。 |

三组新图按统一画布定位（640×630 和 1280×1260），只做等比缩放、透明画布定位和 WebP 压缩，保留生成的透明度。浏览器按屏幕选档。原始 PNG 保存在本地忽略目录 `work/home-gate-masters/`，不参与运行。题签与可操作钥匙为网页元素；图片不拦截点击。
