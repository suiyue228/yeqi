# 夜栖装饰插画

纸艺小剧场的后续13项简洁素材单独位于theatre/，26张WebP共618,470字节；用途、尺寸、生成提示词和处理说明见theatre/README.md及manifest.json。下文三组和165,718字节仅指本目录上一轮道具，不包含剧场。

2026-11-02 使用 OpenAI 内置 image_gen 为本项目生成的装饰图。没有调用第三方图库，没有采用参考图角色、原画面、标志或私人日记内容；不将 AI 生成素材声称为人工绘制。完整生成提示词、源图 SHA256、网页文件尺寸/大小/SHA256 见 manifest.json。这里的说明不是第三方作品许可，也不宣称版权独占。

三组共六张 WebP，165,718 字节（约166 KB），浏览器按 srcset/sizes 选择，不一次读取两档。所有图片保持 alpha；检查过透明四角、深浅背景及页面实际缩小后的效果。宽高预留、object-fit:contain、不覆盖文字；空信封懒加载。无外部图片请求、无额外运行依赖。

统一提示词为平面二维剪纸/线刻绘本、墨黑/夜紫/象牙白/旧金/少量朱红，明确排除文字、写实、3D、霓虹、光晕。具体完整 prompt 字符串按各资产保存在 manifest.json，不依赖聊天记录。心愿瓶生成候选残留光晕，与本轮风格不符，因此未接入和发布，继续保留原 SVG。

原生成 PNG 保持于本机生成目录，并复制至忽略目录 work/art-masters；网页不依赖这些路径。压缩流程：Pillow 12.3 读取 RGBA → 等比 contain 到目标画布95%以内 → 居中置于透明画布 → WebP quality=90/method=6。只缩放、加安全边距、转格式，不用程序去背景或改绘图。无需安装 Pillow 即可启动/构建网站。

后续维护：优先编辑现有素材或生成同风格替代版；更新 manifest 尺寸、字节数、哈希和提示词；检查桌面/移动缩放、透明边缘及失败时可操作性。不要为20—30px状态符号加载复杂插画。生成服务用于开发时创作，浏览器运行时不向生图服务发送任何内容。
