# 夜栖秘仪

2026-11-05接入十二张原创纸艺主题牌、牌背与占卜桌布。图像通过 OpenAI 内置 image_gen 生成，参考本项目已有纸艺配色和轮廓。生成过程没有使用私人记录。完整提示词、源图和参考图的 SHA-256、输出尺寸与校验值见 manifest.json。

三个四宫格原图各含四幅独立插画，按准确象限拆为十二张360px方形图。牌名、罗马编号和卡牌框通过网页排版，便于阅读和键盘访问。牌背与桌布各提供普通及高清两档，共十六张 WebP、284,890字节。
