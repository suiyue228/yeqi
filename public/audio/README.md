The MP3 is the unmodified official Piano Only download. During playback this
website decodes it to 32kHz PCM, adjusts gain, trims a quiet outer tail, and makes
an eight-second equal-power tail/head overlap for continuous looping. The
recording is not claimed as an original composition or performance by this
project. Credit and license links are also visible in the audio settings.

This recording is used as a background to the interactive Moonlit Treehole
website. Preserve attribution and the license when distributing this project.
Do not claim the musician endorses this project. The artist's usage page also
asks that library tracks not be resold alone, uploaded as music releases, or
submitted to audio-fingerprinting services. No such action is part of this app.

All other interaction sounds are authored in the project; they do not use this
recording. There are no external audio requests at runtime. The first user
activation fetches only the same-origin file packaged here.
